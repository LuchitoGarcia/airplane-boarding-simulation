# Airplane Boarding and Seat Allocation Simulation

## Project Overview
This project simulates the boarding process and seat allocation for an airplane with 275 passengers. Each passenger is assigned attributes such as type (standard, family, frequent flyer), priority, seat row, and boarding time. The simulation evaluates passenger behavior, queue management, and resource utilization to optimize boarding efficiency.

## Features
- **Passenger Dynamics:** Different boarding times based on passenger type.
- **Queue Management:** Priority boarding for business-class passengers, with a chance for others to skip the queue under specific conditions.
- **Family Grouping:** Families board in groups of four before heading to their seats.
- **Path Selection:** Passengers choose aisles based on their seat location.

## Key Results
- **Average Boarding Time:** 32.25 minutes per passenger.
- **Queue Waiting Time:** 24.85 minutes on average.
- **Aisle Utilization:** 92% occupancy during the boarding process.
- **Family Wait Times:** Families waited an average of 9 minutes before boarding.

## Technologies Used
- **Simulation Modeling:** Custom algorithms for passenger flow and queue behavior.
- **Programming Language:** Python
- **Statistics and Analysis:** Evaluation of boarding efficiency and resource usage.
